## Што содржеше v1
1. **Почетна** — nav со MK/EN + „Побарај понуда“, hero (serif наслов + слика), 3 категории,
   грид со 8 производи, темна „За нас“ секција со бројки, „Квалитет“ (3 колони), CTA, футер.
2. **Производ** — галерија, име + латинско име, опис, табела спецификации, пилови за пакување,
   inline форма „Побарај понуда“ со веќе избран производ, слични производи.
3. **Админ** — сидбар, листа производи (MK+EN, статус), панел за уредување со табови MK/EN,
   спецификации клуч→вредност, пакувања како чипови, слики, „Објавен“.

Палета: топла ivory (#F4EFE6) + теракота (#B5552B); фонтови Fraunces + Instrument Sans.
